   - Daily Registration Limit: Max 10 users registered per day.
     * Controlled by `MAX_DAILY_REGISTRATIONS = 10` in `user.controller.js`.
     * Rejects 11th registration attempt with clear message.
   - Daily Message Limit per User: Max 10 messages sent per day across all chats.
     * Controlled by `MAX_DAILY_MESSAGES_PER_USER = 10` in `message.controller.js`.
     * User can send e.g. 5 messages to User A and 5 to User B (total 10).
     * Any further attempt displays a toast notification and preserves user input.
